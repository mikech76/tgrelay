# tgrelay — прокси для Telegram на Android и компьютере

Две сборки, одна идея: взять дешёвый **HTTP CONNECT**-прокси (который Telegram
не понимает) и превратить его в то, что Telegram понимает.

```
Telegram (SOCKS5) → 127.0.0.1:55056 → HTTP CONNECT + Basic auth → прокси-провайдер → DC Telegram
```

**English version: [README.md](README.md)**

## Что в репозитории

| Папка | Что это |
|---|---|
| [`app/`](app/README.ru.md) | Android-приложение: один APK, локальный SOCKS5, настроек минимум |
| [`desktop/`](desktop/README.ru.md) | Windows и Linux: MTProto **и** SOCKS5 одновременно, общий пул прокси |

## Зачем это нужно

1. **В Telegram для Android нет типа прокси «HTTP».** Есть только SOCKS5, MTProto и WEB.
   Купленный HTTP CONNECT-прокси вписать в телефон буквально некуда.
   В десктопной версии Telegram поле HTTP есть — в мобильной нет.
2. **MTProto-прокси с секретом продают отдельно и дороже.** SOCKS5 у многих
   провайдеров — тоже отдельный, более дорогой тариф.
3. **Дешёвые shared-прокси часто не пропускают Telegram**: режут адреса
   дата-центров, нестандартные порты или долгие соединения, а часть пула
   в любой момент мертва.

Проект закрывает все три пункта: переводит HTTP CONNECT в SOCKS5 (и в MTProto
на десктопе), держит пул прокси с повторами и переходом на порт 443, чтобы
один плохой прокси не ронял мессенджер.

Итог: дешёвый HTTP-прокси (~39 ₽) + это приложение ≈ рабочий прокси для Telegram,
без покупки дорогого MTProto-тарифа.

## Android

1. Установите APK из раздела **Releases**.
2. Откройте приложение, вставьте прокси (по одному в строке), нажмите
   **«Сохранить список»**.
3. Нажмите **«Включить»**, затем **«Настроить Telegram»**.

Подробнее: [app/README.ru.md](app/README.ru.md).

## Компьютер (Windows / Linux)

Windows:

```bat
start.cmd
```

Linux:

```bash
chmod +x install-linux.sh
./install-linux.sh
nano .env            # прокси + секрет
./install-linux.sh   # поставит systemd-сервис
```

Поднимаются сразу два прокси: MTProto на `55055`, SOCKS5 на `55056`.

## Настройки (`.env`)

Всё в одном файле рядом с программой. Разделы, комментарии, по одному
прокси на строку:

```ini
# 1. ПРОКСИ
PROXY=user:password@1.2.3.4:9405     # основной
PROXY=user:password@5.6.7.8:9829     # запасной
# PROXY=9.9.9.9:8080                 # выключен: закомментирован

# 2. ПОРТЫ
PROXY_PORT=55055                     # MTProto
SOCKS_PORT=55056                     # SOCKS5
SOCKS_HOST=0.0.0.0                   # 127.0.0.1 = только этот ПК

# 3. СЕКРЕТ MTProto
SECRET=                              # пусто = сгенерируется при первом запуске

# 4. ВНЕШНЕЕ ИМЯ (только если пробросили порт)
EXTERNAL_HOST=                       # например yourname.duckdns.org

# 5. ДОСТУП К SOCKS5
AUTH_BYPASS=127.0.0.1/32,192.168.0.0/24
SOCKS_USER=
SOCKS_PASS=
```

- Всё после ` #` — комментарий.
- Строка целиком с `#` в начале — тоже комментарий.
- Закомментируйте один прокси, чтобы временно его отключить.
- Оставьте `SECRET` пустым: при первом запуске программа предложит
  сгенерировать ключ и сама запишет его в `.env`.

## Где купить прокси

Подойдёт любой провайдер **HTTP CONNECT**-прокси с логином и паролем.

| Что предлагают | Подходит? |
|---|---|
| **HTTP / HTTP CONNECT**, shared IPv4 | да — это то, что нужно |
| SOCKS5 | Telegram понимает его сам, приложение не нужно |
| MTProto с секретом | работает без приложения, но дороже |
| WEB-прокси | нужен свой домен и сервер |
| VPN | другая история |

Дешёвый вариант, которым пользуется автор (ссылка реферальная — цена для вас
от этого не меняется):

- **ProxyMania** — <https://proxymania.me/?r=58869>
- промокод: `USER-4eef3a9758c7dc2a` — **скидка 5%**
- что выбрать в каталоге: тип **HTTP**, **shared IPv4**, страна любая,
  срок — минимальный
- цена: около **39 ₽** за прокси

После оплаты в личном кабинете будут хост, порт, логин и пароль.
В приложении это одна строка:

```
user:password@1.2.3.4:9405
```

Берите 2–3 прокси: дешёвые shared-прокси регулярно умирают, пул заметно
стабильнее одного.

## Ограничения

- **Звонки Telegram через прокси не работают** — ограничение прокси, не приложения.
  Текст, фото, файлы и видео работают.
- Скорость ограничена вашими прокси.
- Десктопная MTProto-часть не реализует fake-TLS (`ee`), поэтому трафик
  не маскируется под HTTPS.
- Это не VPN: через прокси ходит только Telegram, остальные приложения — напрямую.
- На части мобильных операторов DPI обрывает HTTP CONNECT к адресам Telegram;
  через такую мобильную сеть прокси работать не будет.

## Безопасность

- Android-приложение слушает только loopback: из локальной сети и из интернета
  оно недоступно.
- Пароли прокси хранятся локально на устройстве.
- Провайдер прокси видит ваш IP и объём трафика, но не содержимое переписки:
  шифрование Telegram сквозное.
- Не публикуйте свой список прокси и собранные с ним APK.
