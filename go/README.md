# tgrelay на Go

Полноценная десктопная версия: трей с меню, живой статус, настройки,
ссылки и QR, EN/RU. Ядро — MTProto и SOCKS5 поверх пула прокси.

Собрать (из папки `go`):

```bash
docker run --rm -v "$PWD:/src" -w /src golang:1.23-alpine sh build.sh
```

Или локально, если установлен Go 1.22+:

```bash
sh build.sh
```

Результат: `dist/tgrelay.exe` (Windows, с треем) и `dist/tgrelay-linux` (headless).

Размер и память (замер на живой работе):

| | Python-версия | Go-версия |
|---|---|---|
| exe | 20,8 МБ | 4,9 МБ |
| RAM | ~60 МБ | ~17 МБ |

Что совпадает с Python-версией: меню с цветными иконками, статус
(протоколы, прокси, соединения, скорость, итоги), подменю протоколов с
копированием ссылки и QR для локального и внешнего адреса, «Настройки»
с перезапуском после сохранения, язык EN/RU, один экземпляр.

Отличие: QR-код открывается системным просмотрщиком картинок, а не
собственным окном.
